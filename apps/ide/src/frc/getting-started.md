# Get started with FRC

Create a WPILib project, build it with javac, and run it in simulation. Everything runs in this browser tab, and projects are saved in this browser.

Use the WPILib commands from the command palette (F1, then type "WPILib") or the WPILib button in the editor title bar.

Built with [CheerpJ](https://cheerpj.com), which runs WPILib 2026 projects, and [java-web](https://github.com/Project516/java-web), which runs WPILib 2027 projects.
